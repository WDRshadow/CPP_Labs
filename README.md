## Installation

1. Clone the repository

2. Ensure you have a C++ compiler and `cmake` installed. At least C++17 and `cmake` 3.10 are required.

3. Build the project:
    ```sh
    mkdir build
    cd build
    cmake ..
    make
    ```

## Usage

To run the main program, execute the following command from the `build` directory:
```sh
./CPP_Labs
```

## Testing

```sh
./CPP_Labs --utest
```
